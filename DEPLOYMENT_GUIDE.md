## 📋 Checklist de Próximos Passos

### 1. **Configurar Cloudinary para Upload de Imagens**

O site está pronto para receber suas fotos de produtos via Cloudinary (serviço gratuito de armazenamento de imagens).

**Como fazer:**

1. Acesse [cloudinary.com](https://cloudinary.com) e crie uma conta gratuita
2. Faça upload de suas 25+ fotos de produtos
3. Para cada foto, copie o link (URL)
4. Envie os links via WhatsApp (+55 41 98868-1605) e nós adicionamos ao site

**Alternativa:** Você pode enviar as fotos diretamente via WhatsApp e nós fazemos o upload para você.

### 2. **Publicar o Site**

**Opção A: Usar Manus (Recomendado)**
- Clique no botão "Publish" no painel de controle do Manus
- O site será publicado automaticamente em um domínio temporário
- Depois você aponta seu domínio (kasasissi.com.br) para lá

**Opção B: Exportar para GitHub e usar Vercel/Netlify (Gratuito)**
- No Manus, exporte o projeto para GitHub
- Conecte o repositório no Vercel ou Netlify
- Ambos oferecem hospedagem gratuita com domínio customizado

### 3. **Configurar Seu Domínio (kasasissi.com.br)**

Você já tem o domínio registrado. Agora precisa apontá-lo para o site:

**Se usar Manus:**
- Siga as instruções no painel de controle para adicionar domínio customizado

**Se usar Vercel/Netlify:**
- Adicione o domínio nas configurações do serviço
- Atualize os DNS do seu registrador (GoDaddy, Registro.br, etc.)

## 🎨 Design e Estilo

O site foi desenvolvido com **Minimalismo Nórdico com Calor Terroso**:

- **Cores principais**: Branco gelo, cinza claro, bege quente, marrom natural
- **Tipografia**: Playfair Display (títulos) + Lato (corpo)

Todas as páginas seguem este estilo consistentemente.

## 📱 PWA (Progressive Web App)

Seu site é um PWA, o que significa:

- ✅ Funciona offline
- ✅ Instalável no celular (como um app)
- ✅ Carregamento rápido
- ✅ Funciona em qualquer navegador

Os usuários podem instalar clicando em "Adicionar à tela inicial" (mobile) ou "Instalar" (desktop).

## 🛠️ Manutenção

### Adicionar Novas Páginas
Se precisar adicionar novas seções, o site está estruturado para isso. Cada página está em `/client/src/pages/`.

### Atualizar Conteúdo
- Textos: Edite diretamente nos arquivos `.tsx`
- Imagens: Use Cloudinary e atualize os links
- Cores: Edite `/client/src/index.css`

### Suporte Técnico
Se tiver dúvidas ou problemas:
1. Consulte a documentação do Manus
2. Verifique os logs do servidor
3. Teste em diferentes navegadores
